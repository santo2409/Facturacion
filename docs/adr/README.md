## Formato

Cada ADR sigue la estructura:
- **Estado**: Propuesto / Aceptado / Deprecado / Reemplazado
- **Contexto**: Problema y alternativas evaluadas
- **Decisión**: Qué se decidió y por qué
- **Consecuencias**: Impacto positivo y negativo
